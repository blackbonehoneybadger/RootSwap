# RootSwap

See [rootswap/README.md](rootswap/README.md) for full documentation.

RootSwap is a privacy-focused, non-custodial where possible crypto exchange aggregator (Telegram Bot + Mini App + Backend API).

**Real money is disabled in this version.**

## Quick Start

```bash
cd rootswap
cp .env.example .env
docker compose -f docker-compose.dev.yml up --build
```
